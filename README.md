# VINILMANÍA 🇲🇽✨
> **“Tu idea. Tu estilo. Tu manía.”**

Landing page **PREMIUM**, moderna, visualmente impactante y de alta conversión para **VINILMANÍA**, estudio creativo mexicano especializado en corte de vinil textil, adhesivo, stickers troquelados die-cut, termos personalizados, letreros y soluciones B2B para negocios.

---

## 🚀 Características y Funcionalidades

- **Identidad Visual Disruptiva**:
  - Mezcla entre estudio creativo, marca de stickers, personalización streetwear y diseño gráfico contemporáneo.
  - Paleta de alto contraste: Morado Eléctrico (`#7C3AED`), Rosa Neón (`#EC4899`), Amarillo Volt (`#FACC15`) y Negro Profundo (`#0D0D11`).
  - Efectos visuales tipo sticker, micro-animaciones y glassmorphism.
- **Enfoque en Conversión (> 5 segundos)**:
  - Integración total con WhatsApp con mensajes prellenados contextuales según cada servicio o producto.
  - Botón flotante permanente de WhatsApp con indicador de mensaje y tooltip interactivo.
- **Módulos Interactivos**:
  - **Header Sticky** con navegación responsive y menú móvil animado.
  - **Hero Section** de alto impacto con mockups de estudio y stickers flotantes.
  - **Franja de Confianza** con 4 garantías reales.
  - **Catálogo de 8 Servicios** con tarjetas interactivas y cotización directa por categoría.
  - **Sección Hecho Para Ti** de conexión emocional y diferenciación de marca.
  - **Personalizador Dinámico "¿Qué quieres personalizar?"** con 9 categorías interactivas (Playeras, Termos, Tazas, Regalos, Stickers, Empaques, Negocios, Eventos, Letreros).
  - **Galería "Inspírate" con Lightbox** modal interactivo a pantalla completa y filtrado dinámico.
  - **Módulo B2B para Negocios y Emprendedores** con checklist comercial y cotización corporativa.
  - **Proceso en 4 Pasos** ilustrado para máxima claridad.
  - **Cotizador / Formulario Validado** con salida directa a chat de WhatsApp y modal de éxito.
  - **Preguntas Frecuentes (FAQ)** con acordeón interactivo fluido.
  - **Footer Completo** con enlaces directos, redes sociales y marcado de copyright 2026.
- **Optimización Técnica & SEO**:
  - Marcado estructurado Schema.org `LocalBusiness`.
  - Open Graph y Twitter Card metadata.
  - 100% Mobile-First y Responsive.
  - Cero dependencias pesadas: Construido con HTML5 semántico, CSS3 Vanilla y JavaScript modular ultraligero.

## 🛠️ Despliegue Local y Visualización

Al ser una aplicación web estática de alto rendimiento, puedes abrirla directamente en cualquier navegador o servirla localmente:

### Opción 1: Abrir directamente
Doble clic en `index.html`.

### Opción 2: Servidor local (Python / Node)
```bash
# Con Python
python -m http.server 3000

# Con npx serve o live-server
npx serve .
```

Visita `http://localhost:3000` en tu navegador.
