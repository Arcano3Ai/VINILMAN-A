## ✂️ Especificaciones para Plotter de Corte

1. **Formatos Vectoriales**: Todos los archivos SVG están construidos con trazados limpios y cerrados listos para importarse en programas de corte como *Silhouette Studio*, *Cricut Design Space*, *Roland CutStudio*, *Illustrator* o *CorelDRAW*.
2. **Uso de Versiones Monocromáticas**: Para cortes a 1 solo color en vinil adhesivo o vinil textil termotransferible, utiliza `logo_monochrome_black.svg` o `logo_monochrome_white.svg`.
3. **Corte a Registro / Capas**: Para cortes multicolor, desagrupa `logo_principal.svg` para separar las capas de morado, rosa, amarillo y blanco.
