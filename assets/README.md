# 📁 Directorio de Assets y Multimedia - VINILMANÍA

Estructura organizada para almacenar todos los recursos multimedia, logotipos, videos, fotografías y elementos de marca del proyecto.

---

## 🗂️ Organización de Carpetas

```plaintext
assets/
├── logos/          # Logotipos oficiales en formato vectorial SVG (horizontal, vertical, dark, monocromáticos, isotipos).
├── videos/         # Videos promocionales, reels de procesos de corte, loops de fondo para hero y clips de unboxing.
├── images/         # Fotografías de producto en alta resolución, mockups, banners y sesiones de estudio.
├── icons/          # Iconografía personalizada, badges en SVG, stickers gráficos y recursos UI.
├── fonts/          # Archivos de tipografías locales (.woff2, .ttf) si se requieren offline.
├── docs/           # Catálogos en PDF, listas de precios, plantillas de corte y guías.
└── favicon.svg     # Favicon oficial del sitio web.
```

---

## 📹 Recomendaciones para Videos (`assets/videos/`)
- **Formatos sugeridos**: `.mp4` (H.264 para compatibilidad universal) y `.webm` (para máxima compresión en web).
- **Resolución sugerida**: 1080p (Full HD) o 720p optimizado para evitar tiempos de carga lentos.
- **Videos verticales**: Ideales para secciones de reels y procesos de depilado/corte de vinil.

---

## 🖼️ Recomendaciones para Imágenes (`assets/images/`)
- **Formatos sugeridos**: `.webp`, `.jpg` (calidad 85%) o `.png` (con transparencia).
- **Fotografía de producto**: Relación 4:3 o 16:9 con buena iluminación y detalles de textura en vinil.
